Set up a phone

  1. Put a SIM card with SMS credit in an Android phone and keep it on a charger.
  2. Install Termux and Termux:API from F-Droid (the Play Store versions cannot send SMS).
  3. Open Termux and run pkg install termux-api curl jq, then allow Termux:API to send SMS when asked.
  4. In Android settings, turn off battery optimisation for Termux so it keeps running with the screen off.
  5. Add the phone above, then run the command shown with its key. Its state turns Online within a few seconds.
